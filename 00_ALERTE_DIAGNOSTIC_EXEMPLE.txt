║                      UTILISATION                                  ║
╚═══════════════════════════════════════════════════════════════════╝

1. Démarrer application:
   npm run dev

2. Ouvrir Console (F12)

3. Exécuter diagnostic:
   window.runFullDiagnostic()

4. Alerte s'affiche automatiquement

5. Cliquer [OK] pour fermer

6. Voir console pour détails complets

║                  AUTRES FONCTIONS DISPONIBLES                     ║
╚═══════════════════════════════════════════════════════════════════╝

Ces fonctions N'AFFICHENT PAS d'alerte (console uniquement):

• window.checkSessionId()        → Vérifier isolation
• window.checkConsoIntegration() → Vérifier conso.js
• window.checkTableDuplicates()  → Vérifier doublons
• window.checkTableSaves()       → Vérifier tables

Seul window.runFullDiagnostic() affiche une alerte visuelle.

DÉPANNAGE RAPIDE

Problème: Tables disparaissent après F5
  → Vérifier logs: "✅ Table saved" lors modification
  → Vérifier IndexedDB contient les tables
  → Vérifier logs: "✅ [Bridge] Table trouvée" après F5

Problème: Contamination entre chats
  → Vérifier log: "📍 SessionId depuis DOM" (pas sessionStorage)
  → Vérifier data-session-id dans DOM (F12 > Elements)
  → Recompiler React si currentSession undefined

Problème: Aucune sauvegarde
  → Vérifier claraverseProcessor chargé
  → Vérifier script inline intégré (__integrated = true)
  → Attendre 20 secondes max après chargement page

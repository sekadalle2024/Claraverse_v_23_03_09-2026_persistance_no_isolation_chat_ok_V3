❌ DÉPANNAGE
============

PROBLÈME 1: "Execution Policy Restricted"
------------------------------------------
ERREUR: Le script ne peut pas s'exécuter

SOLUTION:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Puis relancer:
.\push-claraverse-fixed.ps1

---

PROBLÈME 2: "Connection timeout" ou "HTTP 408"
-----------------------------------------------
CAUSE: Connexion Internet lente ou instable

SOLUTION 1: Relancer le script
   .\push-claraverse-fixed.ps1
   (Il reprendra où il s'est arrêté)

SOLUTION 2: Vérifier la connexion
   Test-Connection github.com -Count 4

SOLUTION 3: Attendre et réessayer plus tard

---

PROBLÈME 3: "Authentication failed"
------------------------------------
CAUSE: Identifiants GitHub invalides

SOLUTION:
1. Vérifier votre nom d'utilisateur GitHub
2. Utiliser un Personal Access Token (PAT) au lieu du mot de passe
3. Créer un PAT sur: https://github.com/settings/tokens
4. Utiliser le PAT comme mot de passe lors du push

---

PROBLÈME 4: Script très lent (> 30 minutes)
--------------------------------------------
CAUSE: Connexion très lente ou fichiers très volumineux

SOLUTION ALTERNATIVE: Utiliser GitHub Desktop
1. Télécharger: https://desktop.github.com/
2. Ouvrir GitHub Desktop
3. File > Add Local Repository
4. Sélectionner: h:\ClaraVerse
5. Cliquer "Publish repository"
6. Attendre la fin de l'upload

✅ GitHub Desktop gère mieux les gros projets !
